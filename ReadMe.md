#  Konya Yemek Dağıtım Optimizasyonu (ACO)

Bu proje, Karınca Kolonisi Algoritması (Ant Colony Optimization - ACO) kullanarak Konya''daki bir yemek firmasının merkezden 20 farklı KYK yurduna yemek dağıtımı yapması için en kısa rotayı belirler.

##  Özellikler
- **Google Maps API Entegrasyonu:** Gerçek koordinatlar ve veriler.
- **ACO Algoritması:** En kısa rotayı bulmak için doğadan esinlenilmiş yapay zeka.
- **Streamlit Arayüzü:** İnteraktif harita ve grafikler.
- **Görselleştirme:** PyDeck ile gelişmiş harita katmanları.
